Панель к MTProxyL **v1.5.2**. Обновление: `mtproxyl panel install` либо
раздел **Обновление** в самой панели.

### Исправлено

- **«Telegram через WARP → вариант C» больше не падает с «sudo: a password is
  required».** В правах sudo, которые панель выписывает себе при установке, не
  было команды `warp on upstream`: вариант C появился в MTProxyL 1.5.1, а
  список остался прежним. Переустановка панели не помогала — файл прав
  генерировался тем же установщиком. Права обновятся сами при обновлении
  панели или командой `mtproxyl panel install`.

- **Панель на самоподписанном сертификате больше не выпускает Let's Encrypt
  сама.** Предложение «выпустить сертификат сейчас?» по умолчанию отвечало
  «да», а при установке без терминала отвечать было некому — установка молча
  уходила к certbot. Теперь без терминала предложение не показывается.

- **Адрес панели с IPv6 печатался нерабочей ссылкой** — адрес склеивался с
  портом без скобок.

### Полезное рядом

После переустановки панели её адрес мог снова становиться голым IP: свой
сертификат она делает самоподписанным. Вернуть домен — `mtproxyl selfmask
panel-cert`; переезд на другой сервер зовёт эту команду сам.

### Требуется

MTProxyL **v1.5.2**. Обновите сначала его: `mtproxyl update`.
