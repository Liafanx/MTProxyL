# MTProxyL-Panel 1.1.7

## Добавлено

**Полное управление WARP.** Панель показывает фактический endpoint, проверки
автовосстановления и все рабочие адреса разведки. Перед включением она отдельно
запрашивает согласие на выключение middle proxy и, в варианте C, маршрутов без
области. Доступны применение сохранённого выбора, ручное восстановление,
обновление warpscout и управление watchdog.

**Понятный выбор WARP.** Действия разделены на выбор узла Cloudflare и точного
IP:порта, показаны фильтр и количество результатов. Фильтр можно снять и
повторить разведку по всем адресам. Блок «Где выходить и через что» расположен
выше разведки и открыт сразу. Выбранный результат используется при
включении A, B или C; без результата панель сначала запускает разведку.

**Настройки HTTPS и логов.** В разделах Selfmask и WEB можно управлять HSTS и
Permissions-Policy. В обычных настройках прокси появился выбор уровня логов.

**Очистка образов движка.** Панель предварительно показывает удаляемые теги и
сохраняет используемые образы, текущую версию и одну версию для отката.

## Изменено

**Надёжный запуск WARP.** Для A/C проверяются локальные порты и при необходимости
выбирается свободная пара; холодный старт получает время на подтверждение.
Разведка `masque` и `masque-h2` использует их фиксированные anycast-адреса без
фильтра узла. Watchdog запускается только вместе с WARP, пропускает совпавшую по
времени ручную операцию и полностью удаляется вместе с MTProxyL.

**Раздел обновлений учитывает оба носителя движка.** Поддержаны Docker и бинарный
telemt через systemd.

Для этих возможностей требуется MTProxyL 1.6.12.

# MTProxyL-Panel 1.1.6

## Добавлено

**Результаты разведки WARP.** На странице «Telegram через WARP» появилась
таблица живых узлов Cloudflare из последней разведки: узел, локация, регион
выхода, задержка и адрес. Локацию и закреплённый эндпоинт можно выбрать прямо
оттуда — раньше их искали warpscout'ом в консоли и вписывали руками.

**Frontend «HAProxy → nginx MTProxyL».** Новый вариант WEB Proxy виден в
статусе и выдаёт свой фрагмент конфигурации HAProxy; PEM для него не нужен.

## Исправлено

**Ссылки на протоколы идут одной строкой.** Кнопки протоколов больше не
рендерятся столбиком и не раздувают высоту строк в списке пользователей
([#60](https://github.com/Liafanx/MTProxyL/issues/60)).

**Разделы MTProxyL получили поля от бокового меню.** «Режим работы»,
«Настройки прокси», Selfmask, WEB Proxy, лимитер, блокировки, бэкапы,
маршруты, эксперт, обслуживание, бот и дополнения прижимались содержимым к
полосе прокрутки. У самого меню появился стабильный жёлоб и отступ справа,
длинные названия обрезаются многоточием.

Для разведки WARP и нового frontend требуется MTProxyL 1.6.10.

# MTProxyL-Panel 1.1.5

## Добавлено

**Внешний HAProxy для WEB Proxy.** В панели можно переключить frontend с nginx
MTProxyL на существующий HAProxy, настроить путь к PEM-сертификату и получить
готовый конфигурационный фрагмент для WEB-only, split или shared с обычным
MTProto на одном публичном порту.

**Управление видимой WEB-заглушкой.** Её можно полностью отключить и оставить
пустой decoy без узнаваемого шаблона. Для новых установок это режим по
умолчанию; статический сайт и приватный HTTP-origin остаются доступны.

Для этой возможности требуется MTProxyL 1.6.8.

# MTProxyL-Panel 1.1.4

## Добавлено

**Выбор сайта-заглушки в WEB Proxy.** В разделе WEB доступны встроенные
шаблоны, URL файла `index.html` и папка с готовым сайтом — так же, как в
Selfmask. Новый источник разворачивается при применении WEB.

**Реверсивная гео-блокировка.** Можно разрешить подключения только из
выбранных стран либо вернуться к блокировке выбранных. Панель показывает,
применены ли правила и включено ли их восстановление после перезагрузки, а
также позволяет переприменить правила вручную. Режим можно выбрать до
добавления стран; пустой список не ограничивает подключения.

## Исправлено

**Обновлены зависимости Go.** Устранены уязвимые версии сетевых,
криптографических и Unicode-модулей.

Для новых режимов гео-блокировки и выбора WEB-заглушки требуется MTProxyL 1.6.6.

# MTProxyL-Panel 1.1.3

## Добавлено

**Редактор пользовательского nginx.conf.** В разделах WEB Proxy и Selfmask
можно создать конфиг из текущего рабочего, редактировать его целиком, проверять
через `nginx -t` и возвращаться к автоматической генерации. В пользовательском
режиме MTProxyL не перезаписывает файл при изменении настроек Selfmask или WEB.

**Переключатель транспорта WEB.** В разделе WEB Proxy можно выбрать только WEB
либо MTProto + WEB, а главная страница показывает текущий транспорт.

## Изменено

**Раздел пользователей учитывает WEB-only.** Панель не строит обычные MTProto-
ссылки, когда соответствующего listener нет, и оставляет только рабочие
WEB-ссылки.

Для этих возможностей требуется MTProxyL 1.6.5.

# MTProxyL-Panel 1.1.2

## Изменено

**В списке WEB-транспортов корректно отмечен carrier по умолчанию.** Для новых
установок это стабильный `websocket`; сохранённый выбор существующих серверов
не меняется.

## Исправлено

**Флаги стран снова отображаются в разделе гео-блокировки.** Панель больше не
полагается на системные emoji, которые в части браузеров превращались во второй
текстовый код страны. При недоступности изображения остаётся понятная
пиктограмма флага.

Для исправления ложного предупреждения WEB о пользователях и применения
гео-блокировки к обоим портам `split` обновите MTProxyL до 1.6.4.
