# MTProxyL-Panel 1.1.4

## Добавлено

**Выбор сайта-заглушки в WEB Proxy.** В разделе WEB доступны встроенные
шаблоны, URL файла `index.html` и папка с готовым сайтом — так же, как в
Selfmask. Новый источник разворачивается при применении WEB.

**Реверсивная гео-блокировка.** Можно разрешить подключения только из
выбранных стран либо вернуться к блокировке выбранных. Панель показывает,
применены ли правила и включено ли их восстановление после перезагрузки, а
также позволяет переприменить правила вручную.

## Исправлено

**Обновлены зависимости Go.** Устранены уязвимые версии сетевых,
криптографических и Unicode-модулей.

Для новых режимов гео-блокировки и выбора WEB-заглушки требуется MTProxyL 1.6.6.

# MTProxyL-Panel 1.1.3

## Добавлено

**Редактор пользовательского nginx.conf.** В разделах WEB Proxy и Selfmask
можно создать конфиг из текущего рабочего, редактировать его целиком, проверять
через `nginx -t` и возвращаться к автоматической генерации. В пользовательском
режиме MTProxyL не перезаписывает файл при изменении настроек Selfmask или WEB.

**Переключатель транспорта WEB.** В разделе WEB Proxy можно выбрать только WEB
либо MTProto + WEB, а главная страница показывает текущий транспорт.

## Изменено

**Раздел пользователей учитывает WEB-only.** Панель не строит обычные MTProto-
ссылки, когда соответствующего listener нет, и оставляет только рабочие
WEB-ссылки.

Для этих возможностей требуется MTProxyL 1.6.5.

# MTProxyL-Panel 1.1.2

## Изменено

**В списке WEB-транспортов корректно отмечен carrier по умолчанию.** Для новых
установок это стабильный `websocket`; сохранённый выбор существующих серверов
не меняется.

## Исправлено

**Флаги стран снова отображаются в разделе гео-блокировки.** Панель больше не
полагается на системные emoji, которые в части браузеров превращались во второй
текстовый код страны. При недоступности изображения остаётся понятная
пиктограмма флага.

Для исправления ложного предупреждения WEB о пользователях и применения
гео-блокировки к обоим портам `split` обновите MTProxyL до 1.6.4.
