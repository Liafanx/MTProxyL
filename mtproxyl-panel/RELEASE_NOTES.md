# MTProxyL-Panel 1.1.2

## Изменено

**В списке WEB-транспортов корректно отмечен carrier по умолчанию.** Для новых
установок это стабильный `websocket`; сохранённый выбор существующих серверов
не меняется.

## Исправлено

**Флаги стран снова отображаются в разделе гео-блокировки.** Панель больше не
полагается на системные emoji, которые в части браузеров превращались во второй
текстовый код страны. При недоступности изображения остаётся понятная
пиктограмма флага.

Для исправления ложного предупреждения WEB о пользователях и применения
гео-блокировки к обоим портам `split` обновите MTProxyL до 1.6.4.
