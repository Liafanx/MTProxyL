Панель к MTProxyL **v1.4.9**. Обновление: `mtproxyl panel install` либо
раздел **Обновление** в самой панели.

### Новое

- **Дата-центры Telegram на дашборде** — таблица сразу после ошибочных
  соединений: RTT, писатели (живых / нужно) и покрытие по каждому DC. Это
  связь движка с Telegram, а не доступность прокси для клиентов. Данные
  берутся из REST API движка, в Prometheus такой разбивки нет.
- **Уникальные IP на странице «Трафик»** — отдельная колонка и число в
  карточке «Всего». Раньше в режиме менеджера там всегда были нули: адреса
  считает только API движка.
- **Прокси для Telegram на странице бота** — локальный SOCKS5 на случай, когда
  серверы Telegram с хоста недоступны напрямую. Прокси поднимаете вы.
- **Рекламная метка пользователя** ([#28](https://github.com/Liafanx/MTProxyL/issues/28))
  теперь доезжает до сервера и в режиме менеджера: поле в карточке
  пользователя, пустое значение снимает метку.

### Исправлено

- **Правка параметров zapret2 включала Smart By-MEKO.** Кнопка «Сохранить и
  применить» выбирала действие по сохранённому режиму лимитера, а не по тому,
  что изменили, и лимитер по своей взаимоисключающей логике останавливал
  zapret2. Теперь переприменяется та подсистема, к которой относятся
  изменённые параметры.
- **Установка панели падала на проверке sudoers** там, где пути в
  `config.toml` записаны в одинарных кавычках: значение уезжало в правило
  вместе с кавычками, и `visudo` отвергал файл целиком.

### Требуется

MTProxyL **v1.4.9** — панель зовёт его новые команды (`dc status`,
`secret adtag`). Обновите сначала его: `mtproxyl update`.
