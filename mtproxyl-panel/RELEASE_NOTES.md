# MTProxyL-Panel 1.0.13

## Блокировка IP адресов

Новый раздел в боковом меню. Адреса и подсети из списка не доходят до сервера —
правила применяются в nftables и переживают перезагрузку.

- ввод адреса или подсети с проверкой формата: IPv4 с маской 0-32, IPv6 с маской 0-128
- комментарий к записи
- выбор действия: `drop` — молча отбрасывать, `reject` — отвечать отказом ICMP
- счётчик отбитых пакетов и трафика по каждой записи, с временем последнего срабатывания
- выгрузка списка файлом и загрузка обратно, с сохранением комментариев

Формат списка:

```
#сканеры
1.1.1.1/32
2.2.2.0/24
#клиент
3.3.3.3
```

Строки с `#` — комментарии, они сохраняются при выгрузке и загрузке.
Некорректные записи пропускаются, но из файла не удаляются.

Требуется MTProxyL 1.5.5 или новее.
